# 示例数据说明

`attractions.json` 是为 TravelOps Copilot 演示而编写的**原创合成数据集**。其中的场所名称、简介、价格、营业时间、联系信息和 `synthetic://` 来源标识均为虚构内容；城市名称仅用于构造检索条件，并不表示这些场所真实存在。

## 允许与不允许的用途

| 可以 | 不可以 |
| --- | --- |
| 本地开发、接口联调、单元/集成测试、作品集录屏 | 用于订票、导航、安全判断、消费决策或对外宣称为实时信息 |
| 演示检索、引用、约束校验和工作流字段 | 将数据改头换面后说成来自真实平台、真实客户或真实业务数据 |
| 替换为已获授权的公开数据前的占位样本 | 把虚构价格、营业时间或“来源”当作事实传播 |

## 许可与来源边界

- 数据作者：本仓库维护者；数据性质：仓库内原创合成示例；
- 第三方素材：未包含第三方图片、爬取页面正文、商户文案或平台导出的数据；
- 使用许可：与仓库根目录的许可证保持一致；如仓库未提供许可证，则请在对外复用前取得维护者许可；
- 来源标识：`source_url` 使用 `synthetic://travelops/...`，它是可追溯的内部样例 ID，**不是网页 URL**；
- 版本：见 `sources_manifest.json` 的 `dataset_version` 与本文件变更记录。

## 替换为真实数据前的最小检查

1. 记录每条数据的原始来源 URL、获取日期、许可或使用授权；
2. 不复制受版权或平台条款限制的大段描述；优先保存结构化事实及简短、可再核验的摘录；
3. 删去或脱敏个人信息、订单信息、精确住址和内部操作信息；
4. 把来源、许可、更新时间写入新的 manifest；
5. 在预生产环境重新运行评测，不沿用合成数据上的任何指标。

## 字段约定

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 稳定的合成记录 ID |
| `name` | string | 虚构场所名 |
| `city` | string | 演示用目的地条件 |
| `category` | string | 场景分类 |
| `summary` | string | 原创、简短的合成描述 |
| `price_cny` | integer | 虚构的单人参考价格，非报价 |
| `hours` | string | 虚构的展示时间，非营业承诺 |
| `tags` | string[] | 用于检索/偏好匹配的标签 |
| `source_title` | string | 合成来源标题 |
| `source_url` | string | `synthetic://` 内部来源标识 |

## 变更记录

- `synthetic-v1`：初始演示集，12 条原创合成记录；无真实地点、商户、订单或用户数据。
