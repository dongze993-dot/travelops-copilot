# ADR-0003：使用免费公开资料查询补充未知目的地

- 状态：已采用
- 日期：2026-09-22

## 背景

合成知识库适合验证确定性工作流，但不能覆盖全国城市和县城。公开演示需要让输入上饶等未知目的地时返回真实可打开的资料来源，同时不能要求访问者注册、绑卡、填写 API Key 或承担额外调用费用。

## 决策

Netlify v3 增加两个独立接口：

- GET /api/v3/free-attractions：只含目的地/偏好、允许短时 CDN 缓存的来源查询；
- POST /api/v3/free-plans：以同次来源的 ID 组织候选日程。

服务端只读查询中文维基导游和中文维基百科的 MediaWiki 接口。它不调用 DeepSeek，不调用付费搜索，不爬取页面全文，也不接收备注、联系人、预算或工单内容。

## 输出边界

- 每条资料保留来源 URL、标题、短摘要、来源 ID 和获取时间；
- 没有来源时返回空结果和待补充状态，不借用别的城市或虚构景点；
- 预算按天数、人数和节奏生成粗略区间，并把中位估算分配到景区与体验、餐饮、市内短途、小额伴手礼和机动预留；不含往返交通与住宿；
- 不将摘要写成实时票价、营业状态、预约可用性或预订承诺；
- 每个函数保留每 IP 每分钟 3 次的限流，查询结果短时缓存。

## 取舍

优点是部署无需任何 Key、账号或付款，来源可打开核验，未知城市/县城可获得公开资料补充。

代价是它不是通用全网搜索，资料覆盖和更新程度取决于公开页面；没有对应资料时必须如实返回空结果。实时票价、美食价格和开放状态仍需要使用者行前到原始来源或官方渠道确认。

## 验证

tests/free_public_sources.test.mjs 使用 fake public-source response 验证上饶等目的地的 URL 清洗、敏感备注不出站、短时缓存、空结果、超时、预算标签和 v3 函数限流。CI 不访问外部站点，也不需要任何 Key。
