# 免费公开资料查询说明

## 目的

Netlify v3 为中国城市、县城等目的地提供一个无需账号、无需绑卡、无需 API Key 的公开资料查询入口。输入目的地后，服务端只读查询中文维基导游与中文维基百科，并把可打开的原始页面链接、短摘要和获取时间返回给页面。

它用于让未知城市不再被本地合成资料限制；它不是全网爬虫、订票、地图、实时价格或支付服务。

## 数据最小化

服务端只把目的地和由预设白名单映射出的旅行偏好词发送给公开资料站点，用于补充景点候选。不会发送备注、联系人、预算、工单内容、密钥或支付信息。

页面不调用 DeepSeek，不调用任何付费搜索服务，也不存储访问者资料。请不要在目的地字段中输入姓名、电话、订单号或其他个人信息。

## 免费来源

- 中文维基导游：面向旅行主题的公开条目；
- 中文维基百科：当维基导游资料不足时的公开补充条目。

两者均通过只读 MediaWiki 查询接口访问。项目会返回原始来源链接，便于使用者自行打开核验。

## 预算口径

v3 不把资料摘要伪装成景区票价或菜单价格。它会从受限的公开条目摘要中提取同时具备“金额”和“费用语境”的记录，并保留金额原文与来源 URL。只有计价单位明确、且该原文没有同时给出多个互斥票种时，才会做多人小计。

用户填写的是游玩预算上限，不含往返交通与住宿。未标价的餐饮、市内出行和伴手礼不会被补成假精确总价；同一条原文中的通票、单票等选择也不会相加。任何小计都是可确认的局部费用，不是实时价格、报价或完整出行总价。

## 真实边界

- 公开资料不保证覆盖每一个县城，也不保证条目完整或最新；
- 找不到对应条目时，系统明确返回空结果，不会借用其他城市或编造景点；
- 票价、开放状态、餐饮价格、交通和预约要求必须在出行前打开来源页或官方渠道核验；
- DeepSeek 常规 API 不能单独充当通用网页搜索器，因此本功能不把它当作联网数据源；
- 任何公开资料查询都有频率限制和短时缓存，避免对免费来源造成不必要的重复请求。

## 接口

- GET /api/v3/free-attractions：返回目的地的公开资料来源卡片；
- POST /api/v3/free-plans：以同次来源组织候选日程，并返回带原文链接的费用依据与可安全汇总的局部小计。

两个接口均保留来源 URL、获取时间、短时缓存状态和行前确认提示。函数级限流为每 IP 每分钟 3 次，来源查询结果可短时缓存。

## 部署与验收

部署到 Netlify 时不添加环境变量，不填 DeepSeek Key，不填任何其他 Key，也不进行付款或绑卡。部署成功后，输入上饶等目的地并勾选免费联网查找公开资料，页面应显示中文维基导游或中文维基百科的可打开来源。

CI 使用本地 fake response 测试输入边界、URL 清洗、缓存、空结果、超时、预算标签与接口限流配置；CI 不会访问公开资料站点。
